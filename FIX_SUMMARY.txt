# ⚡ CoffeeFriend PWA - Quick Fix Reference

## 🚨 Problem
```
"Access denied" when clicking links
```

## ✅ Solution
```
Updated paths to be RELATIVE instead of ABSOLUTE
```

---

## 🔧 What Changed

### manifest.json
```
❌ "/coffeeapp/pageone.html"  →  ✅ "./pageone.html"
❌ "/coffeeapp/"              →  ✅ "./"
```

### sw.js  
```
❌ '/coffeeapp/pageone.html'  →  ✅ './pageone.html'
❌ '/coffeeapp/'              →  ✅ './'
```

## 🚀 Test It Now

### Step 1: Open Command Prompt/Terminal
```
Windows:     Press: Windows Key + R, type: cmd
macOS:       Press: Command + Space, type: terminal
Linux:       Press: Ctrl + Alt + T
```

### Step 2: Navigate to App Folder
```
Windows:
cd d:\Favorites\OneDrive\Desktop\coffeeapp

macOS/Linux:
cd /path/to/coffeeapp
```

### Step 3: Start Local Server
```
Python:
python -m http.server 8000

OR

Node.js:
npx http-server -p 8000 -o
```

### Step 4: Open Browser
```
Visit: http://localhost:8000/install.html
```

### Expected Result
```
✅ Page loads
✅ NO "Access Denied"
✅ Beautiful installation guide displays
```
